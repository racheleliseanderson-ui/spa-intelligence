# Spa Intelligence

Vanity or Vice · Northern Lantern House Labs

See the room before you book it. Four questions name the service, the setting, the performer, and the product — then the desk prints what nobody told you. It scores disclosure, not quality.

Live: [spa.vanityvice.blog](https://spa.vanityvice.blog) · Method: [vanityvice.blog/spa-intelligence](https://vanityvice.blog/spa-intelligence/)

## What it is

A disclosure instrument. Education only. No diagnosis, ranking, or candidacy.

| Desk | Job |
| --- | --- |
| Four questions | Menu line, setting, performer, product. |
| Your reading | Named (place), marketing pressure, and the gap. |
| Consult questions | What to say out loud before you book. |
| Paste a menu | Extract what the copy actually said. |
| The rest of the room | Jurisdiction, sanitation, after-hours, consent, price. |
| What if | Sensitivity — one hypothetical fill at a time. |
| Compare | Up to five settings, disclosure only. |
| Claim decoder | Separate the literal claim from the implied promise. |
| Library | Quote the menu, not the mood. |
| Decision packet | Print what is still open. |

Save stays in this browser. Nothing is transmitted.
